# 番茄钟 · 置顶部件 三版原型设计稿

为 Tinycast 新增原生番茄钟功能的第一步：确定桌面上「置顶小部件」的形态。本文给出三个
方向的设计稿，供选型；视觉稿见同目录 `index.html`（本地起服务打开）。

---

## 设计前提（三版共用）

**风格锚点**：Tinycast 自身的 HUD / 调色盘语言——behind-window 毛玻璃 + 40% 黑色
scrim、白色 alpha 墨阶、连续圆角、玻璃只上浮在悬浮控件上。部件必须读起来像
Message HUD 的「常驻版」，而不是第三方挂件。次级参照：Apple Dynamic Island（环境感
的存在）、航电仪表盘（环形版的可读性）。

**表面与墨色**（取自 `Theme.Colors`，Dark 基线）：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `panelScrim` | 黑 0.40 | 部件表面（scrim 叠在 behind-window blur 上） |
| `textPrimary` | 白 1.00 | 倒计时数字 |
| `textSecondary` | 白 0.60 | 阶段标签、次要信息 |
| `textTertiary` | 白 0.40 | 任务名、脚注 |
| `controlSurface` | 白 0.10 | 控制件底 |
| `controlHover` | 白 0.16 | 控制件 hover |
| `border` | 白 0.20 | 描边 |
| `brand` | rgb(134, 59, 255) | 专注阶段的唯一着色点 |

阶段色只染「标记」（圆点 / 环弧 / 徽章），从不染表面——与 DialogTone 只染图标的
规则一致。短休用系统绿、长休用系统蓝，都是固定色相、随外观自适应。

**排版**：SF Pro 系统字阶。倒计时数字一律 **等宽数字**（SF Mono / tabular-nums），
秒位跳动时宽度不抖。阶段标签用 caption 级。

**几何**：连续圆角（部件本体 26 或 24，内层控件 10–12，胶囊控件取半高）；间距
遵循 `Theme.Spacing` 的 8pt 节奏；相邻同心圆角按 ui.md 的 concentric 规则。

**窗口行为（三版一致）**：`NSPanel`，`level = .floating`，非激活（不抢焦点）、
可拖动、记住位置；可选「点击穿透」。计时结束走 Tinycast 自己的 HUD（MessageHUD
胶囊）+ 系统通知，绝不用 `NSAlert`。时长与阶段可在设置面板调整。

**番茄逻辑**：专注 25 分 → 短休 5 分 → 专注 25 分 → … → 第 4 个后长休 15–20 分；
一组完成后回到第 1 个。可配置，可跳过，可重置。

## 方案 A ·「静默条」Quiet Capsule

> 最小侵入。一枚贴在屏幕边缘的时间胶囊，静止时几乎不占注意力。

**形态**：横向胶囊（高约 42pt），内部自左向右：阶段色圆点 → 等宽倒计时
`24:31` → 阶段短标签。胶囊底边内嵌一条 **通长发丝进度轨**（1pt，白 0.20 轨 +
白 1.0 已走段），这是它的签名细节——不读数字也知道走了多少。

**状态**：

1. *静止*：胶囊只有圆点 + 数字 + 细标签，约 172×42。
2. *hover*：数字右侧淡入三枚玻璃小控件（暂停 / 跳过 / 展开），胶囊微微加宽，
   不改变高度——高度恒定是它「安静」的关键。
3. *展开*：点击胶囊向下展开一张小卡（约 240 宽）：当前阶段行、第 N 个番茄、
   今日累计、任务名行、快捷操作组。收起只留胶囊。

**记忆点**：像一枚贴在屏幕角落的「时间胶囊」，细进度轨是它的签名。
**适合**：想要完全不被打扰、只在余光里留个读数的人。
**占位**：收起 172×42（三版最小）。

## 方案 B ·「轨道环」Orbit Ring

> 进度是看得见的形状。一眼读完，不用读数字。

**形态**：圆形仪表（约 152×152），自带一块圆形毛玻璃底盘（`panelScrim` + blur，
与胶囊同配方），环与数字是其上的墨——没有这块底盘，白色墨在浅色壁纸上读不出来。
外环是本阶段剩余时间的 **进度弧**（5pt 圆头描边，阶段色；满弧是刚启动，顺时针收短
至零）；环上另有 **4 个刻度点**，代表一组番茄的第几个。中心是大号等宽倒计时
（约 25pt），下方阶段标签。

**状态**：

1. *静止*：纯仪表，没有按钮——这是它与另两版最大的差异。
2. *hover*：环心不变，环外下方浮出一条玻璃胶囊控件（暂停 / 跳过 / 展开），
   与环同心下挂；鼠标移开自动隐去。
3. *暂停*：进度弧改为 0.35 透明度并静止，中心数字旁加一枚暂停小标。
4. *阶段切换*：弧归零 → 阶段色换色 → 新弧起绘，刻度点按组推进点亮。

**记忆点**：余光读弧长，不用读数字；像桌面上的一枚小仪表。
**适合**：视觉型、需要「还剩多少」的形状感的人。
**占位**：152×152（含 hover 控件更高）。

---

## 方案 C ·「桌面台」Desktop Console

> 功能最全的折叠卡。把 Focus Panel 的一角停在桌面上。

**形态**：圆角 24 的卡片，两态。

- *收起*（约 228×66）：左阶段徽章（着色小胶囊：`专注`）+ 中部等宽倒计时
  （约 22pt）+ 右侧细进度条（通长发丝轨，同 A 的签名）+ 今日番茄计数。
- *展开*（约 312×360）：按 Focus Panel 规范排——inset card heading（`专注 · 第 2
  个`）、大号倒计时、通长进度轨、任务名输入行、阶段时长行、中性操作钮（暂停 /
  跳过 / 重置）+ 底部 action group（收起 / 打开设置）。按钮 34pt 高、连续 12pt
  角，装在 18pt 角的组里，与 utility window 完全同构。

**状态**：收起 / hover（收起态尾部浮出控制钮）/ 展开 / 暂停（徽章与数字降低对比，
出现 `已暂停` 脚注）。

**记忆点**：唯一能输入任务名、看今日统计的版本；展开就是个迷你专注面板。
**适合**：把番茄钟当工作台用、需要任务上下文的人。
**占位**：收起 228×66，展开 312×360（三版最大）。

## 三版对比

| | A 静默条 | B 轨道环 | C 桌面台 |
| --- | --- | --- | --- |
| 静止占位 | 172×42 | 152×152 | 228×66 |
| 进度表达 | 发丝轨 | 环弧 | 发丝条 |
| 控制件 | hover 浮现 | hover 下挂 | hover + 展开面板 |
| 任务名 | 展开卡内 | 展开卡内 | 常驻可输入 |
| 今日统计 | 展开卡内 | 展开卡内 | 收起即可见 |
| 信息密度 | 低 | 中 | 高 |
| 桌面存在感 | 极轻 | 环境感 | 明确的工作台 |

**建议**：若只选一版先做，**B 的环形 + A 的发丝轨**可以合成一版（环形主视觉 +
收起态退化为 A 的胶囊）；C 作为后续「展开态」增强。三版共用同一套窗口行为、
阶段逻辑与 HUD 完成通知，差异只在部件本体。
